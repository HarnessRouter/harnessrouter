智能体网关使用说明

在一个工作区中管理智能体运行环境、模型密钥、任务和扩展。

创建并运行智能体

  1. 打开“使用自己的密钥”，添加模型服务商密钥。
  2. 在“开始”中描述任务，选择运行环境和模型，保存配置。
  3. 在工作台打开配置，发送任务并实时查看回答、工具调用和生成文件。

可以选择 Codex、Claude Code 或其他 智能体运行环境。

扩展能力

在“扩展”中添加技能、插件、MCP 工具和执行环境，然后将它们关联到配置。

连接应用

创建 API 密钥后，使用配置页面中的接口地址和智能体 ID 从应用后端发送任务。密钥应存放在后端环境变量中。

管理任务与账户

在工作台查看任务历史、运行状态和执行记录。通过“个人资料”修改登录用户名和密码。
