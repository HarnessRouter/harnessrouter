# 运行记录工作区

2026-11-17 用户要求：运行记录中间为运行状态流程图，支持重放，右侧为属性栏；左侧运行记录列表支持展开和收起。

## 行为与边界

- 仅修改 client，复用当前任务导航和视觉令牌。当前运行列表为示例，显式标注“示例运行”；不冒充 FastAPI 权威历史，不新增后端接口。
- 运行页占满可用主区域，主内容只保留带依赖箭头的 DAG 流程图，可缩放、平移、适应视图；节点文字与图标同时表达状态。运行标题、来源、状态、记录选择和回放控制收进右侧“运行”Tab，避免与左侧记录列表和属性栏重复。
- 无限画布工具栏提供重放/暂停入口、横向/纵向布局切换、缩小、放大和适应视图；画布滚轮按指针位置执行缩放，空白区域拖拽用于平移，所有入口共享同一回放状态。
- 点击节点，右侧属性栏显示节点、依赖、当前步骤状态和该步骤已出现的事件；尚未发生的输出不可提前展示。未知 Agent、模型、输入、输出不编造。
- 右侧属性栏与对话检查器保持相同的多 Tab 交互：节点、运行、事件、调试。桌面端直接显示，移动端在属性抽屉中复用同一套 Tab 状态和内容。
- 节点 Tab 显示选中节点的状态、依赖和输出摘要；运行 Tab 显示运行快照；事件 Tab 仅显示当前节点已发生的事件；调试 Tab 对尚未接入的服务端调试详情显示明确空状态。
- 重放是客户端只读事件回看：播放、暂停、上一步、下一步、从头、进度定位和返回最新；不发送启动、重试等写请求。没有事件时禁用重放并说明原因。切换运行重置重放、选中节点和定时器。
- 左侧运行列表支持折叠和展开，折叠只隐藏列表，不影响中央流程图和右侧属性栏；移动端以记录选择器替代隐藏的二级导航。右侧属性栏可收起，窄屏以抽屉呈现，支持关闭、Escape、焦点返回。

## 视觉与验收

- 桌面 1440×900：主区域无 max-width 居中卡片，画布占据剩余高度；属性栏宽 300px，图区域比属性栏宽。标题、图例和播放控制固定，只有属性正文滚动。
- 390×844：画布和控制可操作，属性抽屉不撑宽页面，记录可切换；无文档横向溢出。
- 深色使用共享 tokens；选中、完成、运行、待执行使用文字和边框区分；所有按钮有可访问名称和焦点，播放默认关闭。
- 单测覆盖事件投影、并行状态、边界步数、未知节点和 DAG 布局；Playwright 覆盖导航到记录、节点选择、播放/暂停/拖动进度、切换记录、左侧列表折叠、右侧四个属性 Tab、桌面/深色/移动截图和无写请求。
- 集成边界为当前客户端示例事件→图→属性栏→重放，不将受控测试记为真实 Provider/服务端事件历史验收。

## 实施步骤

1. 先补重放与布局单测及 UI Red。
2. 提取只读事件投影、DAG 布局和明确来源的数据类型，接入图与属性栏。
3. 接入重放、运行切换和响应式侧栏，保留其他任务模块行为。
4. 运行单测、类型检查、构建和 Chromium/Edge UI 回归；检查关键截图并在变更记录保存结论与哈希。
