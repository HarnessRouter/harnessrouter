# UI 视觉契约

- 设计来源：现有任务工作台、Hexa tokens、Ant Design 控件；用户本次确认 Super Agent 只分发与监工。无外部设计稿，布局由本次实施制定。
- 页面：协调 Agent；Windows Chromium/Edge，1440×900、1024×900、390×844；沿用深色导航与亮/暗主题。
- 结构：页头、创建入口、任务/模板方案、五项状态统计、任务选择与运行汇报。协调 Agent 不作为执行节点，界面使用用户可理解的文案，不展示内部客户端分层说明。
- 状态：空、加载、读取错误重试、启动中、部分分发失败、断线恢复、等待人工、暂停、完成/失败/取消；启动后显示真实 Run 与 WorkflowRevision，不用进度动画模拟执行。
- 交互与可访问性：复选框有任务名称；按钮区分创建、保存、分发、暂停、继续、取消和查看；状态与错误有文本，重要变化通过 polite live 区域告知；控制动作等待服务端返回。
- 几何：沿用 surface/line/primary/status tokens 和 8–12px 圆角；窄屏单列；统计可压缩但不得产生页面横向溢出，触控操作不被隐藏，长输出可换行。
- 验收：自动检查无页面横向溢出、按钮可达、创建/分发/恢复可用；实际检查桌面、深色、移动截图。结构与可操作性为硬性要求；不以截图生成代替观察。
- 证据及功能/视觉结果：统一记录到 change-record.yaml；原始截图与报告保存 client/.artifacts/coordinator/。
