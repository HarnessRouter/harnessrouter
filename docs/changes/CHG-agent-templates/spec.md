# 行为说明

- 需求来源：用户要求 Agent 管理支持拉取 Gateway Agent 模板、客户自定义模板及 list/卡片模式。
- 实施方案：plan.md

## 目标行为

- 智能体页面保留现有 Agent 实例管理，新增模板库；两者均可切换列表和卡片，记住展示偏好。
- Gateway 模板来自现有 `/v1/bases` 的基础 Agent 定义，显示来源、运行时、默认模型及可用状态。不可用定义可以查看、复制为自定义模板，不能直接用于创建。
- 客户自定义 Agent 模板由 Hexa 应用后端按用户持久化，支持新建、编辑、删除、从 Gateway 模板复制及使用模板创建 Agent。保存模板不创建远端 Agent；使用模板先预填可编辑创建表单，用户提交后才创建。
- 模板字段为名称、说明、运行时、默认模型、系统提示词；Gateway 模板只读，不自动复制凭据、插件、环境或远端绑定。

## 边界与非目标

- Agent 模板与任务工作流模板是不同领域；不复用 task_templates 的工作流结构，不修改任务模板行为。
- 浏览器仅访问受保护 App API，Gateway 地址与 Key 继续只在服务器；沿用来源检查、用户隔离和错误脱敏。
- Gateway 读取失败与自定义模板读取独立，失败保留上次列表、表单草稿并提供重试；删除需确认。
- 不修改 gateway/、运行时、Docker、认证策略或恢复任何 Cloud 功能。本次模板仅包含基本 Agent 创建字段。

## 验收

- 模板库展示 Gateway `/v1/bases` 数据及客户模板，可按来源筛选、按名称/运行时/说明搜索。
- 新建/编辑模板后刷新仍可读取，其他用户无法读取或修改；空白必填字段、超长输入返回安全 422；未认证访问返回 401。
- 使用模板预填名称、运行时、模型、提示词，允许编辑；成功创建后重读权威 Agent 列表，失败保留输入。
- Gateway 失败不隐藏客户模板；列表失败保留数据，刷新恢复；Gateway 模板不提供编辑/删除。
- 两种布局内容与操作一致，刷新保留视图；1440×900 和 390×844 无横向溢出，深色模式可读，切换按钮有名称和选中状态。
- 无待澄清项；“Gateway 模板”按已核实的 `/v1/bases` 目录映射，不虚构上游模板 API。
