# UI 视觉契约

- 设计来源：用户文字需求；现有 AppAgentsPanel、AppTasks 与 client/styles.css 的海军蓝导航、白色/深色表面、Ant Design 控件。无用户附图。
- 页面/平台/视口：智能体管理，Web Chromium/Edge；1440×900、390×844。
- 结构：保留 Agent 列表标题，页内“我的 Agent / 模板库”；工具栏包含搜索、来源（模板库）和“卡片视图 / 列表视图”选中按钮。模板显示来源、说明、运行时、模型和明确操作。
- 状态：加载、无数据、搜索无结果、上游失败/重试、保存/删除失败及保留内容；自定义模板编辑/删除，Gateway 模板只读、可复制。禁用使用的模板有文字原因。
- 可访问性：可见表单标签、按钮名称、tab/aria-selected、视图 aria-pressed、alert/status；Ant Modal 焦点与 Escape，提交中防重复。
- 几何/颜色：复用 hx tokens，12px 圆角和细边框；卡片自适应网格，列表桌面一行，窄屏内容与操作换行；移动按钮至少 44px 高。
- 验收：检查两种布局的内容及操作一致、390px 文档无横向溢出、长模型/名称换行、深色可读、键盘选择与表单可操作；采用结构和几何断言，无像素截图基线阈值。
- Red/Green、截图路径、哈希和分项结论：见 change-record.yaml。
