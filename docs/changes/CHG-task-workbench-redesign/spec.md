## 目标行为

用户进入“我的任务”“运行记录”“模板管理”或“对话”时，看到与已确认设计稿一致的全高工作台，而不是继续使用旧的任务卡片、运行画布或浮层检查器：

- 我的任务、运行记录、模板管理使用白底、顶部筛选条和单一 table，不插入状态或日期分组行。
- 每个管理页右侧都有从工作区顶部贯穿到底部的详情栏；三页在 1440px 下统一为 720px，更窄桌面下按 `clamp(400px, 64%, 720px)` 收缩，并保证列表至少保留 280px。
- 详情栏可拖动左边缘调整宽度，三页分别记忆本页宽度；可收起为 44px 把手，收起后列表自动扩展，再次展开恢复本页宽度。
- 三页列表都支持列表/卡片切换；卡片上方为工作流缩略图，下方为文字信息，选中项同步右侧详情。
- 运行记录详情内部为“执行轨迹 + 实时事件”双列，原有运行流程图通过明确入口保留。
- 任务详情直接展示已采用结果与最近运行节点输出；`查看流程图` 在“我的任务”内打开最近运行快照，`返回任务详情` 回到原详情，不强制跳转运行记录。
- 对话页使用“对话历史 + 会话主线程 + 会话上下文”三栏；上下文栏宽 304px、全高、可收起为 44px 把手。
- 桌面视口下主工作区不产生横向滚动；移动端保留可访问的列表、详情抽屉和上下文抽屉。

与当前行为的主要差异：移除任务详情浮层 Drawer、模板卡片网格、运行记录独立画布主视图和对话页覆盖式检查器，改为稳定的全高分栏。

## 边界与非目标

- 本次只升级前端布局、交互和视觉；不新增或修改 Task / Run / Template / Conversation 后端接口。
- 继续使用当前客户端已有会话、Agent、模型、附件、模板编辑和样例任务数据；不把样例数据写成新的权威状态。
- 运行流程图保留为“打开流程图”次级入口，不作为运行记录默认主视图。
- 模板编辑器继续使用现有无限画布、节点连线、保存新版本和返回列表行为。
- 不恢复 Cloud 部署、上传到 hosted provider、目标工作区、余额、密钥握手或 hosted provider 入口。
- 不新增 Team、权限、外部队列或任务执行语义。

## 验收

### AC-1 我的任务表格

入口：进入“我的任务”。
操作：查看列表，切换状态筛选，搜索任务，点选一行。
预期：白底，顶部筛选和搜索，单一 table，无状态或日期分组行；选中行与右侧详情同步；页面无横向溢出。

### AC-2 我的任务详情栏

入口：进入“我的任务”桌面视口。
操作：测量详情栏，点击收起，再点击展开把手。
预期：详情栏从工作区顶部贯穿底部，1440px 下展开宽度 720px；可拖拽调整并记忆本页宽度；收起后宽 44px 并释放列表宽度；恢复后回到本页记忆宽度。

### AC-3 运行记录

入口：进入“运行记录”。
操作：筛选或点选 Run，查看右侧详情，打开流程图。
预期：列表为单一 table；右侧详情在全高清栏内展示执行轨迹与实时事件，1440px 下宽 720px、窄桌面按容器收缩；流程图通过次级入口打开。

### AC-4 模板管理

入口：进入“模板管理”。
操作：筛选或点选模板，查看右侧详情，进入编辑器。
预期：列表为单一 table；右侧详情为全高栏，1440px 下宽 720px、窄桌面按容器收缩；编辑器仍可返回列表并保存新版本。

### AC-5 对话页

入口：进入“对话”。
操作：查看会话主线程和右侧上下文，收起上下文。
预期：对话历史仍在左侧上下文侧栏；会话主线程与右侧上下文都从工作区顶部贯穿底部；上下文宽 304px，收起后 44px；输入框始终可见。

### AC-6 响应式和无溢出

入口：1440×900 与 390×844 视口。
操作：打开四个工作台页面并切换到详情。
预期：桌面无横向滚动；窄桌面三页详情不少于 400px 且列表至少保留 280px，不产生内部溢出；移动端隐藏固定详情分栏并可打开对应抽屉；页面 `scrollWidth` 不超过视口宽度。

### AC-7 既有行为回归

- 任务筛选、搜索、时间筛选仍工作。
- 模板编辑器的返回、添加节点、编辑节点名称和保存新版本仍工作。
- 对话发送、继续对话、刷新恢复、附件和 Agent/模型选择仍工作。
- 现有运行记录选择、运行属性与重放功能仍可从流程图入口访问。

### AC-8 任务详情直达结果与流程图

入口：进入“我的任务”，选中一条任务。
操作：查看“任务结果”，点击“查看流程图”，再点击“返回任务详情”。
预期：详情直接显示已采用结果和最近运行节点输出；运行输出标注 Run / Workflow 版本和只读快照，且不与已采用节点重复；流程图在“我的任务”内打开最近运行快照，返回后回到原详情，侧栏不切换到“运行记录”；草稿任务显示只读结构预览和“尚未运行”。
