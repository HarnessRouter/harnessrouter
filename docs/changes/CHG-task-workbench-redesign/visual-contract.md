# UI 视觉契约

- 设计来源、版本、状态：`docs/design/task-workbench-redesign/design-spec.md` v1.4（2026-11-18），用户确认的 table/卡片 + 全高可拖拽详情和三栏对话方案。
- 目标页面、平台、视口、渲染环境：我的任务、运行记录、模板管理、对话；Chromium/Edge；桌面 1440×900，中间宽度 1280×900 / 1024×900，移动 390×844。
- 结构、内容、可访问性：
  - 管理页左侧为单列 table，顶部有范围筛选、搜索和页面操作；不使用分组行。
  - 左侧列表可切换为卡片视图，卡片上方为工作流缩略图、下方为文字信息；切换后选中项继续同步右侧详情。
  - 右侧详情为 `complementary` 区域，从主工作区顶部贯穿到底部；左边缘有 `separator` 拖拽手柄，收起按钮和展开把手均有可访问名称。
  - 运行详情内部显示“执行轨迹”和“实时事件”两列；模板详情显示结构、阶段、版本和只读说明。
  - 对话主线程和上下文栏为同级全高列；上下文栏保留 Agent、模型、连接、上下文、文件、审批和工具标签。
- 交互状态、失败、恢复：筛选、搜索、选中、列表/卡片切换、详情拖拽/收起/展开、运行流程图入口、模板编辑返回、对话发送/恢复、移动端抽屉；保留已有错误和加载提示。
- 几何、颜色、圆角、响应式：
  - 桌面应用壳 rail 64px、上下文侧栏 248px；1440px 下三页管理详情统一为 720px，更窄桌面宽度下按 `clamp(400px, 64%, 720px)` 收缩并保证列表至少 280px；详情可拖拽且三页分别记忆宽度，最小 400px；对话上下文 304px；收起把手 44px。
  - 白底表面、1px 分隔线、克制阴影；沿用现有 Ant Design token 和 Hexa 深色 rail。
  - 900px 以下隐藏固定上下文侧栏和任务详情分栏；640px 以下对话上下文使用现有的固定抽屉/遮罩。
  - 运行记录和模板管理的筛选组独占工具条首行，搜索框自适应；列表按容器宽度隐藏耗时/进度列，不截断筛选项。
- 验收方法、容差或检查项及制定依据：Playwright 以可访问角色定位，断言主工作区顶部对齐、详情/上下文全高、三页 1440px 下均为 720px 且误差不超过 1px、拖拽与键盘调整生效、各页宽度独立记忆、收起恢复本页宽度、任务最后一行贴合底部状态栏、容器无内部横向溢出、无页面横向溢出、composer 可见；截图人工核对与设计稿的结构和密度差异。
- 目标测试 Red/Green 证据：`client/tests/app-ui/workbench-redesign.spec.ts` 先确认旧布局失败，再在实现后通过；同时更新 `tasks.spec.ts`、`run-history.spec.ts`、`navigation.spec.ts`、`chat.spec.ts` 回归。最终 Chromium 20/20、Edge 20/20；新增任务到 Run 映射断言覆盖供应商风险评估 Run #13 与竞品功能对比 Run #15。
- 结构化报告、独立报告、截图、哈希：最终截图和哈希写入 `change-record.yaml`；生产截图位于 `docs/screenshots/task-workbench-redesign/`。
- 功能：通过。目标 Chromium/Edge 各 20/20，Chromium 全量 30/30，客户端单测 20/20，类型检查与生产构建通过。
- 视觉：通过。1440×900 下三页详情栏统一 720px、从 y=0 贯穿到底部，任务行铺满列表高度，运行/模板筛选完整可见；三页卡片视图上方流程图、下方文字信息；390×844 下无页面横向溢出。
- Advisory：构建保留既有大于 500kB chunk 提示；不阻塞本轮。
- 未评估：真实 Gateway/Provider 链路、非 Windows 字体渲染、长文本与超长工作流状态。
