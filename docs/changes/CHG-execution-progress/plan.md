## 方案与依赖

扩展 NodeRun 的 partial_text / execution_json（SQLite 兼容升级和 PostgreSQL 增量迁移），与成功 output 分开。TaskExecutor 接收现有 on_progress / on_execution，按尝试保存脱敏且有界快照，现有 Run SSE 传递至节点属性面板。对话 GET 返回当前请求快照，客户端统一订阅恢复和初次执行，保留 EventSource 原生重连，初次发送按状态变化识别旧快照。Runner 复用统一线程包装器记录生命周期和周期计数，不启用请求正文日志。
