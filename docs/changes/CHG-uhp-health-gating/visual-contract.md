# UI 视觉契约

- 来源：用户批准计划，现有 Console UHP 卡片和主题；无外部设计稿。
- 页面和环境：/uhp，Chromium，1440×900 和 390×844。
- 结构和内容：标题、刷新按钮、保存表单、连接卡片；状态文字、最近检查/成功、延迟、Harness 数量和失败原因；版本独立于健康状态。
- 可访问性：原生按钮和 label；状态更新礼貌播报；错误说明用文字，不只变色；操作期间按钮禁用并显示检查中。
- 失败和恢复：检查失败保留卡片和 Harness；立即检查恢复后更新同一卡片；旧连接显示未检查，过期显示状态已过期。
- 几何和主题：沿用现有 pv-g、btn、line、muted 变量；meta 可换行，长地址和原因可断行；390px 单列且无横向滚动。
- 验收：组件 Red/Green 检查状态、按钮与错误；真实浏览器检查桌面/移动溢出、可读性和交互。证据与未评估项记 change-record.yaml。
- 工作台补充：/studio 卡片和列表显示 UHP 连接文字状态，历史任务统计单独标注；详情状态提示可跳转 UHP 管理页，不可用时新建/发送禁用，历史可打开；1440×900、390×844 检查状态文本换行、禁用反馈、无横向溢出。沿用 pill ok/bad/neutral 和现有任务栏，不增加不同主题。
