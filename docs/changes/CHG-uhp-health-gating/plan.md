- 行为与验收：spec.md。

## 方案与依赖

- 扩展现有 Gateway UHP 保存、probe、Responses 和 Workflow 路径；观察按连接 ID 单独存入既有 vault，使用配置摘要防止旧观察覆盖新配置。
- 本机进行中任务合并；跨副本复用 control_store 连接租约，检测 fence=0 的存储失败，不使用其默认 fail-open 语义放行。
- 保留缺失 Harness 别名；按目标判断调度状态；目录新增 available/health 信息，老调用方继续读取原字段。
- UI 沿用已有连接卡片与主题，补充状态和手动检查，页面刷新触发真实检查。
- 工作台共享健康分类与轮询钩子，读取 `/v1/harnesses` 和单 Agent 详情中的既有观察，不为每张卡片主动探测；任务统计保持独立。补齐 UHP 详情读取，禁用详情新建/发送而不是禁用历史导航。每 30 秒刷新元数据、过期本地计时，焦点恢复触发刷新；避免覆盖任务流状态和迟到跨工作区结果。
