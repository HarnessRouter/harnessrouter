# 行为说明

- 需求：2026-11-16 用户批准的 UHP 连接健康检查与调度保护计划。
- 实施方案：同目录 plan.md。

## 目标行为

- 保存、管理列表读取、手动检查、后台每 30 秒和任务发送前探测 Runtime。健康观察有效期 90 秒，任务发送前始终检查，不使用健康缓存跳过。
- 检查发现接口和已鉴权 Harness 列表；整个检查预算 15 秒、连接超时 5 秒，不执行 Agent 任务。区分 unknown、healthy、unreachable、unauthorized、harness_missing、invalid。
- 检查同步新 Harness，缺失 Harness 保留稳定别名并标记 harness_missing；重新出现后恢复。连接部分 Harness 缺失时，其他 Harness 仍可使用。
- 返回健康时间、最近成功时间、延迟和脱敏错误。状态过期单独标识 stale，不把过期健康宣称为当前可用。
- 新任务和续接发送前检查对应连接和 Harness，不可用时返回 503 及原因，不切换 Agent。查询和取消不因预检被阻断，仍尝试 Runtime；实际连接、鉴权、协议错误更新状态。
- 多个本机并发检查共享一次进行中的探测；有控制存储时用连接租约协调副本，租约/持久化不可用时保留旧观察且拒绝放行未确认目标。
- 工作台 UHP Agent 的连接状态与历史任务统计分开展示；连接正常、离线、鉴权失败、协议无效、目标缺失、未知和过期不能被历史成功覆盖。部分 Harness 缺失不影响同连接其他健康目标。
- 工作台和 Agent 详情每 30 秒读取 Gateway 已有健康观察，重新聚焦/恢复可见时立即刷新；隐藏页不轮询。观察到期即显示过期并阻止新任务及续接，不伪造在线/容量状态。刷新失败保留最后观察但不延长有效期。
- UHP Agent 详情读接口返回与目录一致的健康、可用性和别名，保持组织/工作区/Calibration 隔离。不可用时禁用新建和发送，展示原因与 UHP 管理入口；列表卡片、历史任务阅读和取消不受禁用影响。本地 Agent 沿用任务统计语义。

## 边界与非目标

- 不改 UHP 标准，不增加 Runtime 心跳、忙碌、容量、自动切换、等待恢复或持久化任务自动重发。普通任务错误、409/429 不等于连接离线。
- 保留组织、Workspace、Calibration 和管理员访问控制、SSRF 检查与禁用 HTTP 重定向；错误不回显 URL、Bearer 或上游错误正文。
- 健康记录独立于连接配置，并绑定配置摘要；旧配置的迟到观察不会应用到新配置。老连接按 unknown 处理，无需迁移。
- Workflow 沿用 retry_limit；记录健康错误，并验证没有向不可用目标转发。检查无法消除探测成功到实际执行之间的故障窗口。

## 验收

- 保存产生健康记录；只 probe 不改变状态；管理列表与手动检查更新观察，失败保留连接和已知 Harness。
- 超时、拒绝连接、401/403、无效 JSON/协议/列表、目标移除均阻止上游任务；恢复后同 ID 可重新运行；普通业务失败不污染连接状态。
- 并发检查单飞、租约失败保留状态、配置变更隔离、90 秒过期和生命周期清理有测试。
- Console 显示状态、时间、延迟、数量和错误，支持刷新/立即检查；桌面 1440px、移动 390px 无溢出，状态不只依赖颜色。
- Gateway 单元/接口集成、Workflow、Console 组件测试、类型检查、生产构建及部署 mock Runtime 故障/恢复探针。实际结果统一记录 change-record.yaml。
- 工作台卡片/列表与详情的 UHP 状态、过期、自动刷新和恢复有组件/集成测试；任务发送入口在失效状态拒绝发送，正常后恢复，历史仍可进入；部署后 Chromium 桌面/移动检查实际离线 Agent。
